# 💊 Farmacia_EF

**Farmacia_EF** es una aplicación de escritorio desarrollada con **Windows Forms** y **Entity Framework**, que implementa operaciones ABM (Alta, Baja, Modificación) para la gestión de una farmacia, siguiendo el patrón de diseño **MVC** (Modelo - Vista - Controlador).

## 🛠️ Tecnologías utilizadas

- 🧩 Windows Forms (WinForms)
- 🗄️ Entity Framework
- 🖥️ .NET Framework o .NET Core (según versión)
- 🧠 Patrón MVC aplicado manualmente

## 🗂 Estructura del proyecto
Farmacia_EF/
├── Controller/ → Lógica de control y manejo de eventos
├── Model/ → Clases de dominio y acceso a datos (EF)
├── Farmacia_EF/ → Formularios (Views)
├── Farmacia_EF.sln → Archivo de solución


## 🧪 Funcionalidades principales

- ABM de productos farmacéuticos
- Conexión a base de datos mediante Entity Framework
- Separación clara por capas (Modelo, Vista, Controlador)
- Formularios intuitivos y funcionales
